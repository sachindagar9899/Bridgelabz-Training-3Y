ASSIGNMENT 7 - DOM (9 QUESTIONS)

This folder contains a separate solution folder for each question.
Each question folder contains:
- index.html
- style.css
- script.js
- README.txt

How to run:
1. Extract this ZIP file.
2. Open any Q folder.
3. Double-click index.html or open it in Chrome/Edge.
4. The JavaScript is linked using the defer attribute.

Notes:
- Only HTML, CSS and core JavaScript (ES6+) are used.
- No frameworks or external JavaScript libraries are used.
- Q5 uses six remote sample images from picsum.photos, so an internet connection is needed for those images.
- Q3 displays a masked password in the completion summary.
