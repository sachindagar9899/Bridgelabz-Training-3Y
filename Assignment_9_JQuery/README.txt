ASSIGNMENT 9 - JQUERY (10 QUESTIONS)

Each question has its own folder containing:
- index.html
- script.js
- style.css
- README.txt

Run:
1. Extract this ZIP.
2. Open a question folder.
3. Open index.html in Chrome, Edge or Firefox.
4. Internet access is required because jQuery is loaded from the official jQuery CDN.

Question 9 intentionally loads jQuery 1.12.4 and jQuery 3.7.1 separately, then uses noConflict(true)
to preserve both versions under window.jQueryV1 and window.jQueryV2.
