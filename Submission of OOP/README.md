# Submission of OOP

Solved JavaScript assignment.

- Each question has its own `.js` file.
- Core JavaScript (ES6+) is used; no frameworks.
- Most files can be run with Node.js: `node filename.js`.
- Questions that create forms or use the DOM (form validation, dynamic form builder, booking form, object updater, and product cards) should be opened/run in a browser. Their scripts create the required HTML elements themselves.
- Async examples may use timers and random success/failure, so output can vary between runs.
