ASSIGNMENT 10 - APIs AND ENDPOINTS

Six separate question folders are included. Each has index.html, script.js, style.css, README.txt and its own db.json (minimum five records). Each question uses a different JSON Server port.

Run the command in that folder's README, keep the terminal running, then open index.html. JSON Server is pinned to 0.17.4 for classic --watch and query parameter support. jQuery/Axios questions load libraries from CDNs and require internet.

Q6 sample JSON data is for assignment demonstration only; never store real passwords as plain text in production.
